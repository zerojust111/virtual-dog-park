# 🐶 Virtual Dog Park

A small browser game built in tested rounds, one Git commit per round.

**Status:** setup complete — the scaffold runs, but the park is still empty.

---

## Rounds

| Round | Visible result | Commit message |
| --- | --- | --- |
| Setup | Starter files + Git history | `chore: initialize virtual dog park` |
| 1 | Dog encyclopedia | `feat: add dog encyclopedia` |
| 2 | Adoption + Feed + Play | `feat: add virtual dog adoption and care` |
| 3 | Growth + saved progress | `feat: add dog growth and saved progress` |
| Review | README + final test | `docs: finish instructions and final review` |

## Run

Open `index.html` in a browser, or serve the folder:

```powershell
py -m http.server 8000
# then open http://localhost:8000
```
